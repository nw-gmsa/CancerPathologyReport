This page will describe how the cancer pathology report fits the [IHE Inter-Laboratory Workflow (ILW)](https://wiki.ihe.net/index.php/Inter_Laboratory_Workflow) profile: the pathology laboratory as **Requester** of a sub-order (for example a reflex order to genomics), sending the pathology report as supporting information, and receiving the **Subcontractor**'s results.

See the [Pathology to Genomics Reflex](https://nw-gmsa.github.io/use-cases/PathologyToGenomicsReflex.html) use case and the NHS North West Genomics IG [Inter Laboratory Workflow (ILW)](https://nw-gmsa.github.io/en/ILW.html).
